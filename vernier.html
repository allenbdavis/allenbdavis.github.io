How to read this caliper
  • The main scale has a line every 1 mm. The sliding vernier has 10 divisions labelled 0, .5 and 1.0, so each vernier line is worth 0.1 mm.
  • Outside jaws (top scales): measure the width of an object held between the large jaws. Read the top main scale at the OUTSIDE vernier.
  • Inside jaws (bottom scales): the small step-shaped tips measure the opening of a hole or gap. Read the bottom main scale at the INSIDE vernier.
  • Whole millimetres: the last main-scale line to the left of the vernier 0 line. Tenths: the vernier line that lines up exactly with a main-scale line.
